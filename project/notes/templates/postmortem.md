# Postmortem: <what went wrong> (YYYY-MM-DD)

Blameless. Written after an escaped defect, a wrong "done", a lost day, or a broken rule.

- **What happened:** facts, with timestamps and links.
- **Impact:** who or what was affected, for how long.
- **Why it wasn't caught:** which guardrail was missing or didn't fire.
- **Fix:** the code change.
- **Guardrail:** the one rule, test, hook or check we add so it can't recur. Owner of the change, and where it lives.
