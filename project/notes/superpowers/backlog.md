# Backlog

Private, not in git. The lead grooms it with the owner; lanes don't pick from it directly (see `../board.md`).

## How to read
- **Urg.** set by the owner: 1 = burning, 2 = this iteration, 3 = next, 4 = later, 5 = someday. **Lead** column = the
  lead's suggestion.
- **SP** story points (1, 2, 3, 5, 8, 13). 13 = too big: split or write a spec first.
- **Lane:** A / B / any / lead (data, research) / owner (by hand).
- **Status:** — · `handoff` · `spec` · `in progress A/B` · `PR #N` · moved to "Done" with the PR.
